# MFM-Wishart

This repository contains all material needed to reproduce the results reported in **“Mixture-of-Finite-Mixtures Wishart Model for Clustering Covariance Matrices with an Application to Brain Functional Connectivity”** (Li, Castruccio, & Zhang, 2026).

📄 [Read the paper on arXiv](https://arxiv.org/abs/2605.23207)
